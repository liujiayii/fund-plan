# 模拟基金 · 定投系统

用**真实基金数据**玩模拟盘。真实 T+1 撮合、真实内扣申购费、真实 FIFO 阶梯赎回费，
每日签到领本金。部署在 Cloudflare 免费全家桶上，零成本运行。

> 模拟盘 · 数据来自公开接口 · 仅供学习，不构成投资建议

## 为什么不是又一个玩具

市面上的模拟炒股大多用随机数或简化规则。这个项目较真的地方：

- **真实数据**：基金档案、费率、起购金额、历史净值全部来自东方财富公开接口
- **真实 T+1**：交易日 15:00 前下单按当日净值成交，之后顺延至下一交易日；
  每晚 20:30 由 Cron 拉取当日净值并撮合
- **真实内扣法申购费**：`净申购金额 = 申购金额 ÷ (1 + 费率)`，
  而不是常见的错误实现 `费用 = 金额 × 费率`（外扣法会多收钱）
- **真实 FIFO 阶梯赎回费**：份额按批次先进先出消耗，每批按各自持有天数套费率档。
  同一笔赎回可能同时按 1.5% 和 0.5% 两档计费——这就是为什么需要 `share_lot` 表，
  只存持仓汇总是算不出正确赎回费的
- **整数存储**：金额存「分」、份额/净值存 ×10000 整数，中间运算走 `decimal.js`。
  绝不用浮点数算钱

### 实测数据（本地端到端验证）

申购 1000 元，费率 0.15%，确认日净值 1.3100：

```
净申购 = 100000 ÷ 1.0015 = 99850 分   手续费 = 150 分（1.5 元）
份额   = 998.50 ÷ 1.31 = 762.2137 份
```

赎回 300 份（持有 0 天，命中 `<7天` 档 1.5%）：

```
赎回总额 = 300 × 1.31 = 393.00 元
赎回费   = 39300 × 1.5% = 590 分（5.90 元）
到账     = 387.10 元
```

`share_lot` 与 `holding` 对账完全一致，一分不差。

## 权限矩阵

| 身份           | 看主人组合            | 看自己组合 | 下单 / 定投 / 签到 |
| -------------- | --------------------- | ---------- | ------------------ |
| 游客（未登录） | ✅ 只读（全部公开）   | —          | ❌                 |
| 普通用户       | ✅ 只读               | ✅ 读写    | ✅（仅自己的）     |
| 管理员（主人） | ✅ 读写（即自己的盘） | 同上       | ✅                 |

管理员由环境变量 `ADMIN_USERNAME` 指定，没有独立后台——
主人的 `/me` 就是那个被公开的盘，`/master` 只是它的只读镜像。一份代码，两种身份。

## 功能

- **注册即送 10 万模拟本金**，用户名 + 密码，不要邮箱不要手机号
- **每日签到领本金**：基础 100 元/天，每多连签一天 +50 元，封顶 500 元，断签归零
- **基金搜索与详情**：真实档案、费率、风险等级、净值曲线（1 月 / 3 月 / 1 年 / 全部）
- **买入**：抽屉内按内扣法**实时预估**手续费与份额
- **赎回**：抽屉内按 FIFO **逐批试算**，展示各批持有天数、费率与费用明细
- **定投**：支持日 / 周 / 月，Cron 每日自动扫描下单，可暂停 / 启用 / 删除
- **订单与流水**：全部可追溯，区分手动 / 定投来源与待确认 / 已确认 / 失败状态
- **围观主人盘**：游客免登录查看管理员的持仓、定投与交易流水
- **重置模拟盘**：练废了一键归零，不用重新注册

## 技术栈

| 层     | 选型                                                               |
| ------ | ------------------------------------------------------------------ |
| 框架   | React Router v8（framework mode）+ Vite 8                          |
| 运行时 | Cloudflare Workers                                                 |
| UI     | Ant Design v6 + @ant-design/charts                                 |
| 数据库 | Cloudflare D1（SQLite）+ Drizzle ORM                               |
| 缓存   | Cloudflare KV                                                      |
| 定时   | Cloudflare Cron Triggers                                           |

| 工具   | Zod + dayjs + decimal.js                                           |
| 测试   | Vitest + @cloudflare/vitest-pool-workers（真实 workerd + 真实 D1） |
| 包管理 | **pnpm**                                                           |

## 快速开始

```bash
pnpm install
pnpm db:migrate:local    # 建本地 D1 表（首次必须）
pnpm dev
```

打开输出的 localhost 地址，注册一个账号即可开玩。
要成为「主人」，用 `wrangler.jsonc` 里 `ADMIN_USERNAME` 指定的用户名注册。

### 线上环境

D1 数据库与 KV 已在 Cloudflare 上创建好，`wrangler.jsonc` 里的 id 已填实：

## 测试

```bash
pnpm test          # 领域层单测（纯函数，毫秒级）
pnpm test:workers  # 应用层集成测试（真实 workerd + 真实 D1）
pnpm test:all      # 全部
pnpm lint          # 代码规范检查
pnpm verify        # lint + typecheck + test，提交前全量校验
```

提交时 git 钩子会自动跑：`pre-commit` 对暂存文件跑 `eslint --fix`，
`pre-push` 跑 typecheck 与全部测试。

测试覆盖的关键场景：

- 申购内扣法（含「净申购 + 费用 === 申购金额」一分不丢的守恒校验）
- FIFO 阶梯赎回费（跨档位、乱序入参、碎渣份额）
- 交易日历 T+1（15:00 cutoff、周末节假日、跨 UTC 日界）
- **撮合幂等**（Cron 重试不产生重复成交）
- 净值缺失时订单顺延而非误判失败
- `share_lot` 与 `holding` 对账一致性
- 连签奖励递增 / 封顶 / 断签归零
- 越权防护（不能操作他人的定投计划）

## 已知限制

- **不发邮件**：CF 免费版无 SMTP，故无邮箱验证与邮件找回密码，忘密码需管理员手动重置
- **无盘中实时估值**：`fundgz` 接口从服务器直连被挡；T+1 撮合本身用收盘净值，不受影响
- **节假日表需每年更新**：见 `app/domain/trading-calendar.ts`，有净值日反向校正作为兜底
- **暂无收益率排行榜**：需要快照表 + 结算任务，后期可平滑添加
